# IT_Ticket_Analysis-ExcelDashboard
Interactive Google Sheets dashboard that turns raw IT support ticket data into insights on ticket volume, resolution time, customer satisfaction, and agent performance.

# Explore the interactive dashboard here:
https://docs.google.com/spreadsheets/d/1h1DP_AYnBgLDJ0m69G79iHSXEnZE3W3-Tx4F_5Q_NGE/edit?usp=sharing

# Objective
Track agent performance, ticket resolution efficiency, and customer satisfaction by converting raw ticket data into meaningful business insights for operational reporting.

# Key Features
- KPI cards for total tickets, average resolution time, and customer satisfaction
- Ticket volume trends over time
- Category-wise ticket distribution
- Agent performance comparison
- Interactive slicers to filter the whole dashboard

# Tools & Skills Used
- Google Sheets
- Data cleaning and organization
- Calculated fields
- Pivot tables
- Charts, slicers, and KPI cards

This project strengthened my skills in data analysis, dashboard development, data visualization, and problem-solving.
